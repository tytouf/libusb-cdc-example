USB CDC examples using libusb
-----------------------------

Здесь приведены примеры и исходные коды для работы с libusb cdc в python3 и C.

Код основан на [libusb-cdc-example](https://github.com/tytouf/libusb-cdc-example)

## Python

Необходимо создать venv и доставить в него библиотеки:

```
python3 -m venv usb-venv && source usb-venv/bin/activate
pip install pyusb
python3 main.py
```
